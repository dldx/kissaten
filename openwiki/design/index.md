# Files

- [Analytics & Insights Dashboards](analytics-insights.md) - How Kissaten computes and surfaces database-wide and per-entity statistics, the /v1/stats endpoint, animated home counters, the SunburstChart flavour visualisation, and the InsightCard and ExpertInsightsSection insight components.
- [Bean Detail Page Information Architecture](bean-detail-page.md) - Design documentation for the bean detail page — its information hierarchy, the slug-based load flow, tasting notes and flavour visualizations, origin traceability, roast profile, cupping score, multi-bag price options, recommendation engine, and BeanConqueror share integration.
- [Faceted Filtering System](faceted-filtering.md) - Design documentation for the faceted filtering system — the SearchFilters component, the full filter taxonomy (origin, roaster, process, varietal, roast level, roast profile, price, weight, elevation, in-stock, decaf, single-origin, tasting-kit), URL-driven state management, and the /v1/search API that powers it.
- [Guided Discovery Experience](guided-discovery.md) - Design documentation for the home page journey, the SmartSearch natural-language/image search flow, the CoffeeJourney scroll-animated map, and the flavours/processes/varietals entry points that help users discover coffee without prior terminology.
- [Origin Exploration & Interactive Map](origin-exploration.md) - Design documentation for the country→region→farm origin drill-down, geographic breadcrumbs, elevation visualisation, and the statistics surfaced at each level of the /origins hierarchy.
- [Roaster & Origin Exploration Flows](roaster-exploration.md) - Design documentation for the roaster exploration flow — the roasters listing page with sticker wall, roaster detail page with uniqueness report and flavour distribution, the roaster-to-bean drill-down, and the roasted-in location exploration that groups roasters by where they roast.
