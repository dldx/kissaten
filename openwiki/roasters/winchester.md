# Winchester Coffee Roasters — Roaster Profile

## Overview

Winchester Coffee Roasters (winchestercoffeeroasters.co.uk) is a Hampshire
coffee roaster on a WordPress + WooCommerce storefront in GBP. It roasts all
Arabica coffee weekly to order, offers local pickup from its roastery, and
sells blends and single origins alongside equipment, wholesale and a Coffee
School. The catalogue holds 17 saved coffees.

## Address

- Unit 7a, Sun Valley Business Park, Winnall, Winchester, Hampshire, SO23 0LB
  — United Kingdom.

## Schedules & Shipping

- All Arabica coffee is roasted weekly to order.
- Local pickup available 6 days a week (Mon/Tue/Thu 10am–2pm; Fri–Sun
  8:30am–3:30pm; closed Wednesdays).

## Scraping Quirks

- Public WordPress wp-json API is blocked, so the WooCommerce scraper
  enumerates the catalogue via the HTML `/shop/` listing instead of the JSON
  API.
