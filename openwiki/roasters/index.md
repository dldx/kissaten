# Roaster Profiles

Short, grounded profile pages for the scraped coffee roasters in Kissaten's
catalogue. The format is intentionally generic so it rolls out to every
scraper, wherever the roaster is based. Each page captures what makes the
roaster distinctive — verified address (including country), sustainability
initiatives, roasting equipment, business philosophy and history — plus the
genuine scraping quirks (filter/dedup/domain corrections, kit flagging, mixed
stores) that keep the pages useful to contributors maintaining the scrapers.

> Format reference: [Roaster Profile — Template & Conventions](template.md) —
> read this before adding or editing a profile page.
